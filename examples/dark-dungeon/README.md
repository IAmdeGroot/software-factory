# Dark Dungeon (Example Product)

> This is a **sample product** built by the software factory — not the factory itself.

## Concept

A 2D top-down action RPG / roguelite.

- Explore dungeons
- Fight monsters
- Find weapons and abilities
- Gain power
- Fight bosses

## First Playable Scope

- Player movement
- Melee combat
- 3 enemy types
- One dungeon
- Basic loot
- Character progression
- One boss
- Basic UI

## Technology (tentative)

- **Godot** — 2D game engine
- Data-driven enemy/item definitions
- Fast iteration over content volume

## Status

Not started. Beads for this product will use a `DUNGEON-` prefix when planning begins.

## Why This Example

Small enough to iterate quickly, fun enough to care about, complex enough to stress-test the factory's agent loop.
