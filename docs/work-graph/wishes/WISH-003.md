# WISH-003: Give Dark Dungeon a fresh, beautiful dark-fantasy look

Human wish (2026-09-08): start improving the game's graphics so it feels
extremely fresh and polished.

Keep Dark Dungeon's top-down identity and dark-fantasy mood. Hollow Knight
and Elden Ring are tonal references, not assets or designs to copy. Build a
distinct visual language for this game.

Outdoors should have a strong sense of depth in the background, using
layering, scale, atmosphere, motion, or parallax where appropriate. Interiors
should feel beautiful and dramatic through authored light, shadow, glow, and
environmental effects. Visual improvements should preserve gameplay clarity
and run in Godot 4.
